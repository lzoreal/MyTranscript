# Press 档：把首页排成一页杂志

目标：新增 `data-theme="press"`（暂定名，接管默认位），把现有 `ledger` 首页从"纵向堆卡片"改成
S1 大样的杂志版式。其他 11 档像素不动。

原型：`site/design/specimens.html` 第 1 张（Monocle 路线）。改动只落在 home 区域 + 令牌层，
`base.html` 的 id 一个不删（骨架只加不删）。

## 一屏结构（1180 × 880 参照）

```
┌───────────────────────────────────────────────────────────┐
│ MYTRANSCRIPT ───────── LISTEN · READ ───────── 第 01 期 · 11月 │  ← .topbar 压成 34px 报头
├───────────────────────────────────┬───────────────────────┤
│ 本期专题 / 把收听排成版面            │                       │
│ Listen.                            │   [ 封面 372×372 ]    │  ← #homeContinue 取第 1 张封面
│ Read.           (96px Georgia)     │   图 01 — 节目 / 集名  │
│ 订阅、进度、文字稿排在同一张纸上…    │   ─────────────       │
│ ┌──────────┬──────────┐            │   01 继续收听 · XX 39:27│  ← #homeRecent 前 3 行
│ │ 正文一栏  │ 正文二栏  │            │   02 …                │
│ └──────────┴──────────┘            │   03 …                │
│ ─────────────────────────────      │                       │
│ 14     │ 8507    │ 4              │                       │
│ 档节目  │ 集·时间轴│ 栏版式          │                       │
├───────────────────────────────────┴───────────────────────┤
│ 继续收听          最近更新              推荐播客             │  ← 三栏目录
│ 节目 / 集名        节目 / 集名           节目 / 集名          │
└───────────────────────────────────────────────────────────┘
```

## 区域映射（沿用现有 id，不新增挂载点）

| 现有元素 | press 后的位置 | 说明 |
| --- | --- | --- |
| `.sidebar`（238px） | 0px，整条隐藏 | 导航改由报头右侧一枚"目录"按钮弹出；`#sidebarToggle` 保留并用它开合 |
| `.topbar`（70px） | 34px 报头 | 左 `MYTRANSCRIPT`、中铁线、右期号（`#ledgerDate` 复用为"第 01 期 · 2026 年 11 月"） |
| `.ledger-mast` | 左栏上半 | `h1` 96px Georgia，`Listen.` / `Read.` 分两行，`Read.` 斜体 |
| `.ledger-mast-copy > p` | 左栏 standfirst 19px | 原文案可直接用 |
| `.ledger-search` | 报头下方一条细线搜索 | 高 34px，无圆角、无阴影、仅下边线 |
| `#homeContinue` | 右栏 372×372 封面 + 图注 | 取订阅里最新一集所属节目；封面 372 方图，图注 10px |
| `#homeRecent` | 右栏编号目录 3 条 | 序号 01–03 + 集名 + 时长，行间 1px `#ded8ca` |
| `#homeStats` | 左栏底 "14 / 8507 / 4" 数码条 | 大数字 26px，标签 8.5px 字距 .2em |
| `#homeRecommended` | 底部三栏"继续/更新/推荐" | 每栏一档节目 + 一条集名 |
| `.home-onboard`（0 订阅态） | 左栏正文位置 | 空态文案排成正文段落，不做居中插画 |
| `.ledger-editor` | 并入底部"本期编辑"小栏 | 不再独占右上角 |

## 令牌

```
--press-paper   #f4f1e9      纸底
--press-ink     #1a1a17      正文墨色
--press-rule    #cfc9bb      发丝线
--press-accent  #a8402a      朱红（仅图注编号、kicker、首字）
--press-serif   Georgia, "Songti SC", serif
--press-sans    system-ui / 现有 --sans
字号阶：96 / 52 / 19 / 16 / 12.5 / 11.5 / 10 / 9.5 / 8.5
行高：巨标 0.92、正文 1.85、图注 1.6
```

正文、图注一律纯色，不用阴影、不用渐变、不用圆角；分隔只用 1px 实线。

## 读者页 / dock / 迷你窗

- 读者页：正文栏宽 560px 居中，行高 2.0，词级高亮底改为淡朱红 12% 且不加背景块；右栏笔记降到 300px。
- dock：压成 1px 上下双线之间的 56px 条，播放键保持圆形，其余图标改文字按钮（`继续` / `目录` / `笔记`）。
- 迷你窗 `mini.html` 344×132：只改排版 —— 左 96×96 封面、中铁线、标题两行 + 时长；跟随 press 令牌。

## 验收

1. 首页在 1180×880 下：报头、左栏三块、右栏封面、底部三栏，无横向溢出。
2. 0 订阅态：只有正文与一条"添加 RSS"细线按钮，不出现空卡片、不出现空表格。
3. 切到其余 11 档：像素与 `9d406f71` 之后逐字节一致（骨架不动）。
4. 窗控 `.win-ctl` 在壳里仍可点、可拖整页；报头高 34px 时四颗按钮仍居中。
5. `python tests/test_skeletons.py`、`test_player.py` 全绿。
