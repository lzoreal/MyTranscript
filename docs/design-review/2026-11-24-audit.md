# 设计审计（全应用）· 2026-11-24

**栈**：纯 HTML/CSS + CSS 自定义属性（`--bg/--ink/--accent/...` + 每套主题覆写），无 Tailwind、无组件库；19 个页面容器、15 个主导航路由、3 个插件页；浅色/深色两套都在用。
**实测**：在桌面壳里渲染，1280×900 与 375×812 两档截图，共 19 个页面 × 2 档；字体/间距/圆角/对比度由运行时 `getComputedStyle` 采集；截图与原始指标属于本地临时产物，已清理，不入库。
**口径**：项目已有的 token 体系优先于书的默认值；下面标「约定」的不是缺陷。

## Systemic（修一条顶十条）

1. **没有间距刻度。** 单页 14 个不同间距值、密度分布随机，是 #10 的根因。定 6 档后，卡片内衬、行距、区块间距都能对齐。
2. **没有字号刻度。** 9–11 档并存，`10.5 / 11 / 11.5 / 12 / 12.5` 五档挤在 2px 里，层级靠 0.5px 分辨不了。收成 6 档即可同时消掉 #9 和 #16 的一半。
3. **`--accent` 一词多职。** 同一支红同时承担：大标题（大字）、11px 标签、实心按钮底色。三处对比度需求互相矛盾，必须拆成 `--accent-text`（≥4.5）与 `--accent-fill`（配 `--accentText`）。这是 #3、#4 的根因。
4. **`--dim` 只按层级取值。** 8 套主题全部低于 4.5:1，说明取值时没做对比度校验；应在 `build_theme_packs.py` 或测试里加一条「dim/on bg ≥ 4.5」的门槛（现有测试只覆盖 9 套内置档，未覆盖随包主题）。

## 约定（不是缺陷）

- 编辑风：大写 eyebrow + 字距 + 细线分隔，与「报刊/账本」的定位一致；保留，只需修对比度。
- 首页超大 hero 是品牌决策；本报告只要求它不挤掉主任务（#6）。
- 每张推荐卡自带「订阅」实心按钮，属卡片动作，不按「一页一主按钮」判罚。
