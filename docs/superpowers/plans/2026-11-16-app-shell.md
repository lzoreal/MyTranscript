# MyTranscript 应用外壳与订阅实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `site/player.html` 升级为带完整外壳、站内订阅与多主题的单页应用，并按原型重做播放器。

**Architecture:** 单个 `site/player.html` 承载外壳和播放器，hash 路由切换页面；一个 `audio` 元素贯穿全部页面。新增 `site/catalog.json` 轻量目录，由 `scripts/build_catalog.py` 从 feed 生成并随 publish job 重建。

**Tech Stack:** 原生 HTML/CSS/JS；GitHub Pages 静态托管；Python 3.11 生成目录；本地 `unittest` + Node 提取函数测试。

**Spec:** `docs/superpowers/specs/2026-11-16-app-shell-design.md`

## Global Constraints

- 用户未说“提交”不得 commit；本计划所有任务只在工作区改动。
- `tests/test_player.py` 钉住的字符串与函数必须保留：`shows.json`、`id="showSel"`、`myt-progress`、`saveProgress(true)`、`state.resumeAt`、`audio.currentTime = t`、`mergeCues`、`splitBilingual`、`splitLabel`、`directAudioUrl`、`tryAudioSource`、`smallArtwork`、`renderList`、`alignCue`、`toggleAlignMode`、`alignToCue`、`state.alignMode`、`body.classList.toggle('aligning'`、`rel="preconnect" href="https://stitcher.simplecastaudio.com"`、`const audioUrl = preferredAudioUrl(item);`、`audio.src = audioUrl;`、`tryAudioSource(item.url) || tryAudioSource(item.directUrl)`、`loading="lazy" decoding="async" referrerpolicy="no-referrer"`。

- [ ] **Step 3: 实现站外抓取**

```js
async function fetchFeedText(url){
  const abs = new URL(url, location.href).href;
  const cached = await idbGet(abs);
  if (cached && Date.now() - cached.at < 6*3600e3) return cached.xml;
  try { const r = await fetch(abs, {cache:'no-cache'}); if (r.ok) { const t=await r.text(); idbPut(abs,t); return t; } } catch(e){}
  const tpl = localStorage.getItem('myt-cors-proxy');
  if (tpl) { const r = await fetch(tpl.replace('{url}', encodeURIComponent(abs))); if (r.ok) { const t=await r.text(); idbPut(abs,t); return t; } }
  const err = new Error('无法读取该 feed（站点不允许跨域）。可在设置中配置 CORS 代理，或粘贴 RSS 内容导入。');
  err.cors = true; throw err;
}
```
