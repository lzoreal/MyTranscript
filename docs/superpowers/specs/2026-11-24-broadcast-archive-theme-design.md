# 广播档案室主题（Broadcast Archive）需求梳理

日期：2026-11-24
状态：待确认（空间结构已由用户定下；写实度与档位身份待点头）
落点：`themes/broadcast-archive.css` + `themes/broadcast-archive.json`（自包含包卡，见 [adr/0007](../adr/0007-broadcast-archive-is-a-self-contained-pack.md)）

## 目标

新增一档可切换主题，把界面变成**一间私人广播档案室**：

- 上方：节目档案墙，节目以档案格平铺陈列
- 中间：最近更新的节目，按录音记录条排列
- 底部：一张实体广播控制台，就是播放条

节目是档案，单集是录音记录，字幕是节目文字稿，播放器是控制台。整档要能即时切换，
切回任何一档都不重载页面。

## 不做

- 不做书架、不做陈列柜（用户已明确否掉）
- 不引 Three.js / WebGL，不做可拖动旋转的 3D 空间
- 不改默认档（默认档变了要重拍全部文档截图、重跑各档回归）
- 不动骨架、不改共用渲染器（理由见 ADR-0007）

## 空间结构

| 层 | 屏幕上是什么 | 现有落点 |
| --- | --- | --- |
| 顶 | 档案室招牌：室名、今天、在架节目数、检索入口 | `.ledger-mast` 区（`#heroSearch`、`#ledgerDate`、`#heroSubCount`） |
| 上 | 节目档案墙：每格一个节目档案，格内是封面、标签、最近更新 | `#homeRecommended`（`.pod-grid`） |
| 中 | 最近更新：一条条录音记录，带时长、进度、是否已有文字稿 | `#homeRecent` |
| 中下 | 继续收听：取出的那盘录音，放在台面上 | `#homeContinue` |
| 底 | 广播控制台：电平表、走带、录音灯、机械按键 | `.dock`、`.mini-player` |

## 映射表

| 应用里的东西 | 档案室里的东西 |
| --- | --- |
| 节目（show） | 节目档案：档案格里的文件夹，标签写节目名与在架期数 |
| 单集（episode） | 录音记录：一条带时间戳的记录，含时长与进度 |
| 音频播放器 | 广播控制台：电平表、走带指示、录音灯、机械按键 |
| 逐词字幕 / 文字稿 | 节目文字稿：一张打印纸，逐词高亮像校对笔画过 |
| 播放进度 | 走带位置：带量即进度 |
| 离线单集 | 架上录音副本 |
| 播放列表 / 队列 | 待播记录单 |
| 搜索 | 档案检索卡 |

## 材质与观感

暖胡桃木、金属铭牌、哑光塑料、纸、暖黄灯光；档案格之间有细格栅阴影。
纹理一律程序化生成（内联 SVG 噪声叠渐变），不引外部位图——与液态玻璃、Riso 版画同一套做法。

**立体靠 CSS 3D 变换**（见 [adr/0008](../adr/0008-css-3d-instead-of-webgl.md)）：档案墙整块向后仰 3°，
每只档案夹再各自前倾、悬停时朝观众抬起 42px，封面在里面再浮一层；招牌、台面、侧栏各有一层投影。
不引 Three.js，没有 canvas，8 张卡也不掉帧。窄屏一律回正，不做透视。

## 验收标准

1. 任一档切换到档案室档都是即时的，不需要重载，也没有首屏闪主题
2. 骨架里的 id 一个不丢（`#homeContinue`、`#homeRecent`、`#homeRecommended`、`#homeStats`、`#heroSearch`、`#ledgerDate`、`#heroSubCount`）
3. 现有各档回归全过，七套默认主题的可访问性标准（对比度、2px 焦点圈、`prefers-reduced-motion`）同样满足
4. 控制台抬高后不遮首页内容，1100px 宽窗口下首屏仍能看到一整排档案格
5. 移动端降级为单列档案格，控制台收缩成两行，不做横向拖拽
6. 断网时档案格仍显示（封面与标签来自本地缓存/文字稿，不依赖重新拉 feed）

## 已定

1. **写实度**：平面化实体（纸纹、丝印、低饱和）——用户 2026-11-24 定
2. **档位身份**：与现有各档平级的可切包卡——用户 2026-11-24 定
3. **立体感**：CSS 3D 变换，不用 WebGL——用户要「类似 3D 的效果」，以不撕开主题边界为前提
