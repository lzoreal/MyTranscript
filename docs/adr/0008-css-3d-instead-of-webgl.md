# 档案室档的立体感用 CSS 3D，不引 WebGL

用户要「类似 3D 的效果」。主题是自包含包卡（见 ADR-0007）：CSS 注入即生效、切换即时、
所有档共用同一份 DOM。真 3D（Three.js）必须另起一层 canvas 与场景生命周期，
既是新机制，也会和播放条、阅读页的既有层级打架，切换还要重建场景。

所以立体感全部由 `transform` 完成：档案墙整块 `rotateX(3deg)` 后仰，档案夹各自
`rotateY(±1.4deg)` 前倾并 `translateZ`，悬停抬起 42px、封面在夹内再浮 16px；
招牌、台面、侧栏、顶栏各补一层投影。窄屏与 `prefers-reduced-motion` 下全部回正。

代价：进深只能靠透视与投影「骗」，做不到拖动旋转、镜头推进、真实遮挡排序；
卡片一多，透视会让文字有点斜，所以窄屏直接关掉。要真 3D 就得另做插件，不在这档里。
