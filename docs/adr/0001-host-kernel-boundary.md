# 宿主内核只保留能力服务，业务页面全部插件化

Status: accepted（2026-11-20）

宿主 v2 的内核只保留五类能力服务：播放引擎、存储/离线原语、feed 抓取、桌面 IPC/采集、插件运行时与路由/窗口/布局/主题。首页、播客库、下载管理、字幕、学习都作为功能域插件，设置页最后迁；`home`、`library`、`downloads`、`subtitles`、`study` 各一个插件。

这样做的原因是：只要宿主还持有业务页面，公共插件契约就会继续和宿主内部实现耦合，第一方插件也会继续依赖深桥。把业务页面全部移出内核后，宿主只负责装配和回收，插件才有稳定的接入面。

## Consequences

- 启动必须壳先起，插件页面在激活前由骨架和原生回退承接。
- 旧宿主在一次发布中替换，不保留双壳；发布层保留上一版安装包和数据兼容作为回退。
- 设置页最后迁移，因为它配置宿主本身。

## Considered Options

- 业务页面继续留在内核，只把字幕/学习插件化：改动小，但无法达到“全部插件化”。
- 只保留 OS 与 IPC，播放引擎也插件化：最彻底，但启动链和稳定性风险过大。
