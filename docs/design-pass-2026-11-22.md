# 设计整改实施记录（2026-11-22）

对应评审：[design-critique-2026-11-22.md](design-critique-2026-11-22.md) 第 6 节的三批清单。
本轮把三批全部落到代码，并在真实 Tauri 窗口（1180×880，DPR 1.5）逐屏复测。
截图在 [design-pass-assets/](design-pass-assets/)。

## 一、Batch 1 结构修复

**阅读页不再压字。** 原先 901–1199px 宽时左右栏是覆盖层，右栏展开会盖住正文最后约 5 个字符；
现在断点从 1200 收紧到 1080，1180 宽下双栏展开时正文区实宽 710，正文右边界 766、右栏左边界 934，
中间留 168px。正文行宽仍由 `--reader-w:780px` 控制并居中。

**下载行不再竖排。** 原因是 `.qrow` 根本没有样式，`.mini-btn` 又被锁成 28×28。现在补了整行
flex 布局（标题/体积各占一行、行尾操作区 `flex:0 0 auto` + `nowrap`），`.mini-btn` 改成
`width:auto; min-width:28px; padding:0 9px`。实测行内是「▶ 播放　✕ 删除」一行。

**主题选择只剩一套语言。** 顶栏弹层原来 11 个无名字的圆点（7 个斜纹），现在是与设置页同源的
卡片：96×67，缩略（`--sw-bg` + 底部 `--sw-accent` 条）+ 名称 + 当前态「✓ + accent 环」。
平铺色代替斜纹；名称单行省略，不再出现「玻璃拟态 2.0」换行溢出。

## 二、Batch 2 设计系统收口

- **字号 8 档**：`--fs-micro 11 / --fs-caption 12.5 / --fs-small 13.5 / --fs-body 15 /
  --fs-lead 17 / --fs-h3 20 / --fs-h2 26 / --fs-display clamp(44–60)`。
  `player.css` 里 276 处硬编码字号（含 `font` 简写）改写成 token；阅读正文/时间码/水印等
  按内容缩放的尺寸保留变量计算。
- **中文译文回到可读尺寸**：`body.player-open .cue .zh` 从 `.62em`（11.47px、53% 墨色）
  改为 `--fs-small`（13.5px、72% 墨色），行高 1.62。
- **灰阶三档**：使用侧把 `--soft`/`--meta` 全部并入 `--muted`（29 + 1 处），保留
  `--ink / --muted / --dim` 三级；主题变量本身不动，自定义主题不会被写死。
- **控件尺度**：`--ctl-h 36 / --ctl-h-sm 28 / --ctl-h-xs 28 / --ctl-h-lg 44 /
  --row-h 44 / --ctl-r 10`；`.icon-btn`、搜索框（40 高）、`.dstile`、`.iconbtn`、
  模态卡（14 圆角）统一取 token。
- **图标**：`player.html` 顶部新增 23 个 `<symbol>` 的 SVG sprite；侧栏 15 个导航图标、
  顶栏（侧栏/主题/设置/更多）、窗口控制（迷你/托盘/最大化/还原/关闭）全部换成线性 SVG，
  `stroke-width 1.7`，与 `--icon-sm/lg` 同族。设置图标改为「滑杆」以免看起来像太阳。

## 三、Batch 3 页面重排

- **首页**：主视觉 h1 从 82.6px 降到 `clamp(40,4.4vw,58)`（1180 宽约 52px），mast 栅格
  270→240、gap 44→32、padding 28→20；顶部全局搜索在首页隐藏（`body.on-home`），只留
  hero 搜索框；「继续收听」随之上移约 70px。
- **节目页**：简介 `max-width:68ch` + 3 行折叠 + 「展开简介」；主按钮改为「▶ 播放最新」
  在前、订阅/移除在后；「加载全部单集」从资料卡移到单集卡表头。
- **单集页**：h1 改为单集名，上方面包屑「← 节目名 + 日期/时长」；主操作只留「播放单集」
  与「整集下载」，其余 7 项收进「更多 ⌄」菜单（`<details>`，点外部自动收起）。
- **工具箱**：13 个按钮分成「播放 / 视图 / 学习与 AI / 声音与识别」四组，组标题用 mono
  小字；删掉与「剧集信息」重复的「单集信息」，把「章节 / 剧集列表」改名为「本集章节 /
  全部单集」；快捷键图例收进可展开的 `<details>`（默认一行「⌘ 快捷键 展开」）。
  主题按钮文案固定为「外观与主题」，不再随明暗变成「深色主题」。
- **迷你窗**：`myt://mini-state` 新增 `theme`（bg/panel/ink/muted/accent/line/scheme）与
  `steps`（back/fwd）；迷你窗只赋值，不猜主题；标题栏左侧显示 MyTranscript，步长显示
  −15s/+30s 且数值来自主窗；内边距 10–12px，字幕行高放宽。

## 四、顺带修掉的可用性问题

- 模态打开后焦点落在对话框卡片（`tabindex=-1` + `focus()`），不再一进来就把焦点环套在
  28×28 的关闭按钮上。
- 句内「精听」按钮（240 个）默认 `tabIndex=-1`，键盘不用再空过 240 个不可见按钮；
  工具条的「精听刚才」仍是键盘入口。
- 阅读页顶栏在双栏展开时不再把「主页/剧集/笔记/精听刚才」挤成竖排：标签 `nowrap`、
  按钮 `min-width:44px`、`NOW PLAYING` 在 ≤1320px 隐藏。
